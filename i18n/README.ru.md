## 🔍 Обзор

Данный репозиторий сейчас является дополнением к статье **Event-based Rapid Organoid Imaging**.

На момент этой версии репозиторий содержит лицензию, правила игнорирования и черновую документацию, но не отслеживает исходный код, пакеты, скрипты или активы экспериментов.

## ✨ Особенности

- Канонический каркас проекта для статьи: *Event-based Rapid Organoid Imaging*.
- Включена лицензия Apache 2.0.
- Шаблон `.gitignore`, ориентированный на Python, указывающий на возможное будущее Python-инструментарий.
- Каталог `i18n/` присутствует для многоязычных вариантов `README`.

## 🧱 Структура проекта

```text
RapidOrganoidImaging/
```

- Каталог `i18n/` существует, но файлы README на отдельных языках могут всё ещё ожидать генерации.

Текущие минимальные требования:

